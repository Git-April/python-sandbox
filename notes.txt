Print can have an "end" as a final statement to override the default \n . This allows the next print statement to carry on in the same line instead of the next line.
Example:
print("Hello World!", end=" ")

Variables are case sensitive (I rarely need to think about this).
Example:
a = 4
A = "Sally"

Variables must start with a letter or an underscore, not a number (I rarely need to think about this).

Multiple variables can be assigned to multiple values at the same time.
Example:
x, y, z = "Orange", "Banana", "Cherry"

Multiple variables can be set to the same value at the same time.
Example:
x = y = z = "Orange"

Unpacking: Values in a list or tuple can be extracted into variables all in one line.
Number of values being unpacked into variables much match the number of values in the list or tuple, otherwise it'll throw an error.
Example:
fruits = ["apple", "banana", "cherry"]
x, y, z = fruits

Variable of the same name inside of a function overrides global.
If it exists in the function, it must be defined before it is used - the global one will not be accessed and instead throw an error because it has not been defined yet, knowing that there exists a local variable.
Example:
x = "awesome"
def myfunc2():
    x = "fantastic"
    print("Python is " + x)
myfunc2()

Declaring a variable as global inside of a function allows it to be accessed outside of the function after the function is called.
This can also be used to change an already-defined global variable initialized outside of the function.
Example:
def myfunc3():
    global myfunc3variable
    myfunc3variable = "fantastic"
myfunc3()
print("Python is " + myfunc3variable)

Similarly, nonlocal refers to the variable of the same name outside of a nested inner function.
Example:
def myfunc1():
    x = "Jane"
    def myfunc2():
        nonlocal x
        x = "hello"
    myfunc2()
    return x
print(myfunc1())

On lists [], sets {}, and tuples ():
Mutable: Elements can be modified in lists and sets, but not in tuples
Ordered: The order of elements is maintained in lists and tuples, but not in sets.
Duplicates: Lists and tuples can have duplicates, sets cannot.
Different data types: Allowed in lists and tuples, not in sets.
Lists and tuples are the same except that lists can have elements modified, tuples cannot.
Sets are different from lists in that the order of elements is not maintained, duplicates are not allowed, and every element has to have the same data type.
A frozenset then is an immutable set.

When explicitly declaring the list type (and similar for tuples and sets), list() takes an iterable parameter (a tuple is an example of an iterable) and converting it to a list

Underscore is a catch-all at the end of a match statement if no other cases matched
Example:

kwargs means keyword arguments
args means arbitrary arguements

To only allow positional arguements, and not allow keyword arguments, add , / to the end of the arguments in a function
Example:
def my_function(name, /):
    print("Hello", name)
my_function("Emil")

To only allow keyword arguements, and not allow positional arguments, add *, to the beginning of the arguments in a function
Example:
def my_function(*, name):
    print("Hello", name)
my_function(name = "Emil")

The above two notes can be combined to allow some only positional and some only keyword
Example:
def my_function(a, b, /, *, c, d):
    return a + b + c + d
result = my_function(5, 10, c = 15, d = 20)
print(result)

*args: a parameter starting with a * in a function means an unknown number of positional arguments may be passed to a function. This is received into the function as a tuple.
Example:
def my_function(*kids): #new
    print("The youngest child is " + kids[2])
my_function("Emil", "Tobias", "Linus")

**kwargs: a parameter starting with a * in a function means an unknown number of keyword arguments may be passed to a function. This is received into the function as a dictionary.
Example:
def my_function(**myvar):
    print("Type:", type(myvar))
    print("Name:", myvar["name"])
    print("Age:", myvar["age"])
    print("All data:", myvar)
my_function(name = "Tobias", age = 30, city = "Bergen")

Decorator takes another function as input and returns a new function. putting the decorator @changecase directly above the function applies the change to the following function.
Examples:
def changecase(func): #new
    def myinner():
        return func().upper()
    return myinner
@changecase
def myfunction():
    return "Hello Sally"
print(myfunction())
def beforeafter(func):
    def inner():
        print("Before")
        func()
        print("After")
    return inner
@beforeafter
def test():
    print("During")
test()

The decorator can also take arguments by adding another layer of wrapper to handle the argument

            else:
                a = func().upper()
            return a

    return changecase
@changecase(1)

Generators: The yield keyword makes the function a generator. The function only executes when you iterate over it. They can save memory because values are generated instead of all being stored in memory. They can be looped or the next keyword can be used to get the next value.
If you call more nexts than are available, it errors.
Examples:
def my_generator():
    yield 1
    yield 2
    yield 3
for value in my_generator():
    print(value)
def large_sequence(n):
    for i in range(n):
        yield i
gen = large_sequence(1000000)
print(next(gen))
print(next(gen))
print(next(gen))

Generator expressions can be created similar to list comprehension, using parentheses instead of square brackets.
Example:
gen_exp = (x * x for x in range(5))
print(gen_exp)
print(list(gen_exp))

When the iterator variable in a for loop is not needed to be used, it can be set to an _ instead of an alphanumeric like i
Example:
def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b
gen = fibonacci()
for _ in range(100):
    print(next(gen))

In generator methods, the keyword send can be used to send a value into the generator
Example:
def echo_generator():
    while True:
        received = yield
        print("Received:", received)
gen = echo_generator()
next(gen)
gen.send("Hello")
gen.send("World")

The close method for the generator will skip the rest of the trys and hit the finally block
Example:
def my_gen():
    try:
        yield 1
        yield 2
        yield 3
    finally:
        print("Generator closed")
gen = my_gen()
print(next(gen))
gen.close()
